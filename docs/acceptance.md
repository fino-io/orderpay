# 本地实现与验收

日期：2026-11-03。直接在 main 上修改，未提交代码。

## 交付范围

- Fino v1.7.4 生成 API、SQLite 后端、frontend API Console/Issues、OpenAPI 及部署模板。
- 六个 RPC 已提供本地行为：订单创建与幂等、详情聚合、商户作用域分页、取消、支付入口及管理员审计。
- 写入与审计使用同一 SQLite BEGIN IMMEDIATE 事务，包含金额、订单归属、不可变内容和审计追加约束；请求取消后用独立有界上下文回滚，避免连接残留事务。
- 认证与请求限流集中在 app/auth.go；取消规则由 Order、Payment 模型维护，工作流负责事务及审计。
- 订单详情使用只读快照，已有写锁不阻塞 WAL 读取；写配额在识别幂等重放及业务状态校验后检查。
- 支付受理用例依赖授权端口；测试通过替身验证快照、重复受理和取消，生产装配不注入授权适配器，返回503。
